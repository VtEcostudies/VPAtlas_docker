VPAtlas Mobile App

Quick install — iPhone & Android

iPhone
  1. Open Safari and go to vpatlas.org
  2. Tap Share → Add to Home Screen → Add
  3. Tap the new VPAtlas icon. Use the menu to sign in if you want to submit data.
Android
  1. Open Chrome and go to vpatlas.org
  2. Tap the 3-dot menu → Install app (or Add to Home screen)
  3. Tap the new VPAtlas icon. Use the menu to sign in if you want to submit data.
